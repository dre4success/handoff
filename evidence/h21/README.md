## Why (Run, from Codex's own session logs)

The operator's Codex reviewer in a new project with no hooks was told by the brief to run `wait` in the foreground. Codex hands a running command back to the model every 50 s or so, and each time is a whole model call with the whole conversation (110,000 to 150,000 tokens, mostly cached). In that session (2026-10-25), 95 of 147 model calls were these checks. The 5-hour limit rose about 1.6 points a minute while nothing happened, and reached 99% twice. A Codex session in this repository, with hooks, made no call at all while it waited. This is from `~/.codex/sessions/2026/10/25/rollout-…-01a173bc-….jsonl` (`token_count` events), read by a script outside the repository. The log is the operator's and stays out of it.
