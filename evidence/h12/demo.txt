$ handoff settings codex
Put these two files in this project's .codex/ folder, merged with any already
there, and keep it out of git (add .codex/ to .git/info/exclude). Codex reads
them only in a project it trusts. The next time Codex starts here, it asks you
to review the new hooks: choose Trust all.

Every Codex session in this project then takes the role you give it:
tell it, and it runs handoff role <role>. Without a role, handoff on its own never shows it your decisions.
It gets the brief when its first turn starts and after a summary. When its turn
would end, a hook listens for its work and continues it with what arrives. And
handoff runs outside Codex's sandbox, so its notifications and pop-ups reach
you; handoff decide is forbidden.

.codex/hooks.json:
{
  "hooks": {
    "SessionStart": [
      {
        "hooks": [
          {
            "command": "exec <scratch>/handoff hook brief",
            "timeout": 30,
            "type": "command"
          }
        ]
      }
    ],
    "Stop": [
      {
        "hooks": [
          {
            "command": "exec <scratch>/handoff hook listen",
            "timeout": 86400,
            "type": "command"
          }
        ]
      }
    ]
  }
}

.codex/rules/handoff.rules:
# handoff writes only under .handoff/ and has no network code (proposal §9).
prefix_rule(pattern=["<scratch>/handoff"], decision="allow", justification="handoff runs outside the sandbox so that it can notify the operator")
prefix_rule(pattern=["<scratch>/handoff", "decide"], decision="forbidden", justification="The operator decides, not an agent")
